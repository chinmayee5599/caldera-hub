Custom profile sections from Obsidian notes

Caldera profile modules let you add your own sections to your page. Each module is one Markdown note in Caldera/modules/ in your vault; the note becomes a section titled with its file name. Lists, checkboxes, tables, quotes, links and vault images all work, and the page republishes about a minute after you save.

Updated 2026-10-18 · by mjonesone, LLC

Make a module

  1. Create a note such as Caldera/modules/Reading list.md.
  2. Write ordinary Markdown.
  3. Optional frontmatter: place: side for the right-hand column, order: 10 to sort, publish: false for a draft, title for a different heading.

Ideas

  • Talks and podcasts
  • My stack
  • Office hours
  • What I'm looking for
  • Reading list
  • A changelog of what I shipped

Ask your AI

Tell your AI agent: "add a Talks module with my last five talks". The setup and edit prompts explain modules, so it drafts the note, shows you, and adds only what you approve.

Safe by design

No HTML, scripts or embeds; email addresses and phone numbers are removed. Up to 12 modules. Everything in a module is public.

Try it free. Sign up with GitHub in about 30 seconds, or install Caldera in Obsidian. Sign up with GitHub Install for Obsidian

Questions

Do modules need a plugin update?

Yes, Caldera 0.22 or later.

Can I embed a video?

No embeds; link to it instead.

Can I hide a module?

Set publish: false or delete the note.

Is it free?

Yes.
