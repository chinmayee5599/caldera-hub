Message developers directly

Caldera members can message each other without sharing email addresses. Friends (people who follow each other) write directly; anyone else sends a single request that the recipient can accept, ignore or block. New messages trigger an email alert if they are still unread a minute later.

Updated 2026-10-18 · by mjonesone, LLC

How it works

  • Tap Message on someone's page or Feed post.
  • Not friends yet? They get one request. Replying accepts it; ignoring is silent.
  • Block or report any conversation; delete it for both of you.
  • Email alerts: at most one every 30 minutes per person, off with one click.

Good first messages

  1. Say why you are writing in one line.
  2. Reference their work (a repo or post).
  3. Make one clear ask.

Privacy

Messages are text only and encrypted on Caldera's servers; email addresses are never shown to other members.

Try it free. Sign up with GitHub in about 30 seconds, or install Caldera in Obsidian. Sign up with GitHub Install for Obsidian

Questions

Can anyone message me?

Members can send one request; you decide.

Can I turn off message emails?

Yes, on the Messages page or from any alert email.

Are messages end-to-end encrypted?

No. They are encrypted at rest on Caldera's servers. Note sharing between Obsidian vaults is end-to-end encrypted.

Is it free?

Yes.
