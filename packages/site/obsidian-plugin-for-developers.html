An Obsidian plugin for developers

Caldera is an Obsidian plugin that turns a developer's vault into a public profile: a GitHub city of your repos, AI token usage from Claude Code and Codex, a daily journal, custom sections and a scoreboard, plus end-to-end encrypted note sharing with friends. It is free and open source.

Updated 2026-10-18 · by mjonesone, LLC

Features

  • Living profile at caldera.social/@you, republished as you work.
  • GitHub city and Code section.
  • AI usage by model and provider.
  • Daily journal from your daily notes' caldera_ fields.
  • Custom modules from Caldera/modules/.
  • Private view only you can see, in Obsidian and on the web.
  • Encrypted note cards to friends.

Set up with your AI

Copy the setup prompt from the plugin and paste it into Claude Code, Codex or Cursor. It fills in your page, sets up a daily journal routine and asks before anything goes public. See Obsidian AI agent setup.

Install

  1. Obsidian, Settings, Community plugins, Browse, search Caldera.
  2. Install and enable.
  3. Fill in the Welcome form.
Try it free. Sign up with GitHub in about 30 seconds, or install Caldera in Obsidian. Sign up with GitHub Install for Obsidian

Questions

Is it open source?

Yes, the plugin is MIT-licensed.

Does it read my code?

No. It counts notes and reads local AI logs for token counts.

Does it work offline?

Your vault works as always; publishing needs a connection.

Is it free?

Yes.
