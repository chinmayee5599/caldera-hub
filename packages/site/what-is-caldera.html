What is Caldera?

Caldera is a free, open-source social network for GitHub and Obsidian. Sign up with GitHub and your repos become a living city: districts are projects, buildings are repos, and visitors to your sites and your AI agents move through it live. Install the Obsidian plugin and your vault becomes a living public profile. Members follow each other (mutual follows are friends), message each other, post what they need or recommend on the Feed, join groups and share notes end-to-end encrypted. It is private by default

Updated 2026-10-18 · by mjonesone, LLC

What Caldera does

  • GitHub city. Sign up with GitHub and your public repos become a city at caldera.social/@you/city.html, rebuilt every 6 hours. Private repos appear only if you install the Caldera GitHub app, as padlocked buildings with no names.
  • Living profile. With Obsidian, a public page built on your own device from your vault and republished automatically.
  • Follow and friends. Follow anyone; when you follow each other you are friends. Friends can share any note as an end-to-end encrypted card that lands in their vault as a normal note.
  • Feed and messages. Post "I need..." or "I recommend..." and it reaches the people who match. Message members directly; strangers send a request first.
  • Kudos and views. One-tap kudos and a view count on every page.
  • AI-native setup. One copy-paste prompt lets Claude Code, Codex or Cursor install it and run a daily journal routine.

Who makes it

Caldera is built by mjonesone, LLC. The plugin and core library are MIT-licensed, the reference hub is AGPL-3.0 and self-hostable, and the protocol is open. Source: github.com/schoettle-cmd/caldera.

How private is it?

The plugin reads your vault locally and never uploads it. Only counts, the profile sections you switch on, notes you mark caldera: public, and journal fields you write are published. Shared notes are end-to-end encrypted; the hub stores ciphertext it cannot read. Your identity is a key in your vault, not a password account.

Try it free. Sign up with GitHub in about 30 seconds, or install Caldera in Obsidian. Sign up with GitHub Install for Obsidian

Questions

Is Caldera free?

Yes. The plugin, your profile and friends are free and open source.

Does Caldera need Obsidian?

No. Sign up with GitHub and you get a page and a city with nothing to install. Obsidian adds a living profile, a journal and AI usage, and a GitHub sign-up can move into a vault any time.

Is Caldera an official Obsidian or GitHub product?

No. Caldera is an independent, open-source project made by mjonesone, LLC.
