GitHub city: your repos as a living city

A GitHub city is a visualization where every repository is a building and related repos form districts, so a developer's body of work reads like a skyline. On Caldera, open caldera.social/gh/<username> to see any public GitHub account as a city, or sign up with GitHub to get a live city that updates itself.

Updated 2026-10-18 · by mjonesone, LLC

How a GitHub city reads

  • Buildings are repos. Height grows with commits over the last year, so the work you actually do stands tallest.
  • Districts group repos. On a member's city a district is a project; on a quick preview it is a language.
  • Lit windows mean commits this week. A crane means a repo is being built right now.
  • Private repos appear only if the owner adds them, as padlocked buildings with no names (or anonymous, or hidden).
  • The sky follows the viewer's clock and local weather, from dawn to night.

See any GitHub as a city

  1. Go to caldera.social/gh.
  2. Type a GitHub username and press See the city.
  3. Caldera draws a preview from public data only: public repos, languages and recent commit activity. Previews refresh daily.

If the account already belongs to a Caldera member, you go straight to their real city instead.

Get your own live city

Sign up with GitHub and your city lives on your own page at caldera.social/@you/city.html. It rebuilds from GitHub every 6 hours, shows visitors to your websites as they arrive, and shows your AI coding agents as drones over the repos they are working in. See Turn your GitHub into a living city.

Try it on any public GitHub account at caldera.social/gh, or sign up with GitHub to get your own live city.

A city of cities

Every member's city also sits on one shared map, the World, where friendships show as rays of light between cities.

Try it free. Sign up with GitHub in about 30 seconds, or install Caldera in Obsidian. Sign up with GitHub Install for Obsidian

Questions

Is a GitHub city free?

Yes. Previews and your own city on Caldera are free.

Does Caldera read my code?

No. It uses repo names, languages, sizes and commit counts. It never opens file contents.

Why does a preview look smaller than my real work?

Previews count the 20 most recently pushed public repos in detail and cannot see organization repos or private work. Your own city can include organization and private repos you add.

Can I remove a preview of my account?

Yes. Claim it by signing up with GitHub, or email hello@caldera.social and it is removed.

Does it work for organizations?

Not yet. Previews are for personal GitHub accounts.
