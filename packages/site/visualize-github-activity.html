How to visualize your GitHub activity

The simplest view of GitHub activity is the contribution graph on your profile, which counts contributions per day for a year. To see what you worked on, not just when, use a repo-level view such as a GitHub city on Caldera, where each repo is a building that grows with commits and lights up when it is active this week.

Try the city view in 10 seconds

  1. Open caldera.social/gh.
  2. Enter your GitHub username.
  3. Read the city: tall buildings are your most committed repos this year, lit windows are this week, cranes are being built right now.

Go further: make it live

Sign up with GitHub and your city becomes a page that updates itself. Add a one-line script to your websites and visitors parachute into the district for that site. Add the Claude Code hook and your coding agents fly over the repos they are editing. See Visualize your AI coding agents.

Put it on your profile

Add the Caldera badge to your GitHub profile README so visitors can open your city in one click. See GitHub README badge.

Questions

What is the best way to visualize GitHub activity?

Use the contribution graph for consistency and a repo-level view, such as a GitHub city, for what you actually work on.

Can I visualize someone else's GitHub?

Yes, from public data: open caldera.social/gh/<username>.

Does it include private repos?

Only on your own city, and only if you add them; they appear without names.

How often does it update?

Previews refresh daily. Members' cities rebuild from GitHub every 6 hours, and live visitors and agents show in real time.
