Show private GitHub activity safely

Caldera lets you count private work without exposing it. Private repos you add appear on your public city as padlocked buildings with no names (the default), as one separate anonymous district with no sizes or activity, or not at all. Names, descriptions and code are never shown, and your private view always shows everything to you.

Updated 2026-10-18 · by mjonesone, LLC

Three levels

SettingVisitors see
Padlocked (default)Locked buildings in place: roughly how big and how busy private work is, and which project it sits beside. No names.
AnonymousOne separate padlocked district of identical buildings. No sizes, activity or projects.
HiddenNo trace of private work.

How to set it

  1. Install the Caldera GitHub app on the private repos you choose (read-only metadata; it cannot open files).
  2. Pick padlocked, anonymous or hidden in Settings, in the Obsidian plugin, or with privateRepos in Caldera/profile.md.

Enforced everywhere

The setting applies to your city, the World map, your share card and live feeds, whatever built the page.

Try it free. Sign up with GitHub in about 30 seconds, or install Caldera in Obsidian. Sign up with GitHub Install for Obsidian

Questions

Can Caldera read my private code?

No. The GitHub app reads repository metadata only.

Do private commit counts show?

With padlocked, roughly; with anonymous or hidden, no.

Can I change it later?

Yes, any time; it takes effect on the next page view.

Is it free?

Yes.
