Show your AI token usage on your profile

Caldera can put your AI token usage on your public page: total tokens, a daily chart and shares by model and provider. The Obsidian plugin reads Claude Code and Codex logs on your computer and publishes counts only; other machines and your own products can add counts through Caldera/activity.json.

Updated 2026-10-18 · by mjonesone, LLC

How it works

  1. Install Caldera in Obsidian on the machine where you code.
  2. The plugin reads local Claude Code and Codex logs and adds an AI usage section.
  3. To include more sources, have your AI agent write an ai block (counts by model and provider) into Caldera/activity.json.

What it shows and hides

ShownNever shown
Tokens per dayPrompts and responses
Share by model and providerFile names and code
Window (for example, last 45 days)Costs

Turn it off

Set the ai section to false in Caldera/profile.md, or switch it off in settings.

Try it free. Sign up with GitHub in about 30 seconds, or install Caldera in Obsidian. Sign up with GitHub Install for Obsidian

Questions

Why show token usage?

It is a concrete signal of how much you build with AI.

Does it include API usage from my apps?

If your tools write counts into Caldera/activity.json, yes.

Can GitHub-only members show it?

Token usage needs the Obsidian plugin or activity file.

Is it free?

Yes.
